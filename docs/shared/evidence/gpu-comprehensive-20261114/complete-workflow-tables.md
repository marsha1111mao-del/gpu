# 完整验证请求对照

计时从同组请求发出至最后一个用户命令完成，含上下文/驱动准备、CPU参考、预热、全部输出核验、通信及清理。虚拟机已经启动；不含启动VM的时间。这是本实验验证工作流，不是裸GPU时间或生产推理服务吞吐。

同一配置先计算各独立批次的完整组耗时，再报告均值及最小–最大；输出率先逐批计算后平均，因此平均输出率通常不等于总输出数除以平均耗时。首进程冷初始化与工作顺序保留。
