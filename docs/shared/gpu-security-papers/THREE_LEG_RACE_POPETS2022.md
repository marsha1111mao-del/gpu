## 2. 解决的问题与威胁模型

作者希望在容量和算力受限的 CPU TEE 内保护训练数据，同时利用不可信 GPU 做昂贵线性计算。它属于“可信 CPU 与不可信加速器协作”的数据隐私方案，不是为 GPU 本身建立受保护地址空间的 CCA GPU TEE。

可信部分为 SGX CPU 执行环境；GPU、TEE 外内存及通信可被观察，攻击者可知道公开模型、梯度、标签和先验数据，并观察发布的带噪残差。攻击者控制 Host OS；TEE 失陷及其侧信道属于排除项。安全目标主要是输入隐私，不包含普遍的恶意 GPU 输出完整性或跨 VM 隔离证明。

PyTorch 协调执行，论文给出 TEE/GPU context 与数据流；但没有完整远程证明协议、准确 CPU 型号、全部软件栈/线程/EPC 分页配置或源码供边界审计。损失计算、模型更新与宿主协调状态的可信归属需要进一步说明；Figure 7 把 Loss 放在 GPU context 顶部，不能仅凭图就断言一定明文泄漏，也不能默认全部状态都在 enclave。

## 3. 低秩分解、加噪与执行路径

每层把张量展开为矩阵 X，分解为可信低秩部分 X^(T) 与残差 X^(U)，满足 X=X^(T)+X^(U)。TEE 保存低秩表示，GPU 接收加高斯噪声的残差，分别执行线性卷积；结果在 TEE 合并，ReLU、pooling 等非线性操作在 TEE 内执行，再对下一层输入重新分解。

线性计算在不加噪时可精确相加；残差加噪会改变训练计算。这不同于 Slalom 用掩码并精确消除掩码的机制，也不能把两者的正确性、精度和性能保证直接互换。

TEE 计算使用 R 个主成分代替 N 个完整通道，重新组合卷积权重；GPU 仍处理完整形状的残差。Algorithm 1 用逐个秩一的交替最小二乘和 deflation 近似分解；作者经验取 1–2 次迭代。O(RNhw) 依赖迭代次数有界，不是任意输入精确 SVD 的普遍复杂度和收敛保证。分母为零与数值异常路径没有实现可审计。

反向传播合并两支权重梯度；输入梯度卷积可放 GPU，因为对应公式不直接使用 X。但上游梯度仍可能依赖秘密数据，“公式不含 X”不等于公开梯度不泄密。§6.1 对可信/不可信权重梯度位置的描述与 §3.2/Figure 7 有颠倒，记录为文本不一致，不擅自修正成已验证实现。

低秩向量可减少部分可信存储；TEE 还处理完整的非线性输入/输出，不能据 R/N 就声称 enclave 总内存也同比例缩小。通信、缓冲及中间状态同样需要计算。

## 4. 低秩理论：有效秩、能量与精确秩不能混用

作者定义奇异值归一化后的 SVD entropy：mu_X=-log2(sum_j (s_j/sum_k s_k)^2)。对应有效秩 2^mu_X=(sum_j s_j)^2/sum_j s_j²。Lemma 1 对非零矩阵给出 0≤mu≤log2 N；全零矩阵需额外约定，原定义直接计算会出现零分母。

Theorem 1 假设奇异值按几何级数衰减，令 R=ceil(2^mu)，得到保留至少约 97% 能量。这是带分布条件的能量结论，不能变成任意矩阵的精确秩保证或全输入域的残差敏感度界。

独立反例针对 Theorem 2 印刷形式中对完整线性输出的精确界：令 X=diag(1,0.1,0.01)，奇异值满足几何衰减；2^mu_X≈1.219780，R=2。使用 1×1 卷积权重 W=diag(1,10,100)，得到 Y=WX=I3，mu_Y=log2 3≈1.584963，大于 log2 R=1。

反例说明线性权重可放大被截断的小残差。附录 A.3 将原 X 用 R 项近似表示后作为等式使用，不能据此证明完整 X 的精确输出界。若定理明确限定输入就是精确秩 R 的截断矩阵，常规 rank(WX)≤R 的论证仍成立；这里没有否定该条件性命题，也没有运行攻击或否定全部实验。

附录 A.4 从 SVD 子系数矩阵推导可逆性，但正交矩阵的任意子式未必非零，不能据此认定任意所选低熵行都构成所需独立基。A.5 定理的 log(R+1) 与证明末行 log R+1 不同；仿射变换的秩界应明确精确输入秩和常数向量条件。后续定理同样需要区分近似低秩与精确低秩。

ReLU/max-pooling 后低秩趋势来自附录 C 的随机初始化 VGG19/ImageNet 经验观察，不是所有已训练模型、注意力层或 LLM 的普遍定理。低能量部分仍可能编码敏感属性；保留 97% 平方能量仅对应残差范数比至多约 sqrt(0.03)=0.173，不是 0.03，更不能直接推出实验所用 xi=0.05 的最坏情况界。

## 5. 差分隐私：单次噪声发布与完整训练协议

Theorem 6 使用记录置零的相邻关系和采样率 q=b/B，给出高斯方差 2 Delta2² ln(1.25q/delta)/epsilon²，要求 delta≤q。它不是不加说明即可套用的任意替换记录邻接；替换两个有界记录时敏感度可能另有系数。

作者以 Delta2≤xi sup_i||Xi|| 标定残差噪声。独立分析认为，若用作正式保证，必须实施输入范数界，并对允许域、层、训练状态和对抗输入证明或强制残差比例 xi，而不能用平均能量实验代替最坏情况敏感度。正文定理写 epsilon>0，附录 A.7 推导取 0<epsilon≤1，使用时应保留推导范围。

Table 1 取 xi=0.05、epsilon=1、delta=1e-5；CIFAR 的 b=32、B=50k，ImageNet 的 b=128、B≈1.2m，列出约 0.12/0.11 的 AsymML 噪声尺度，对比 DP-X 的约 2.5/2.2。相同范数界下尺度可约缩小 20 倍、方差约 400 倍，但前提就是合法的 xi 上界；不能把这个比例当无条件隐私增强倍数。

全文未给出覆盖每层、每批、全部 epoch、自适应模型/梯度及联合消息的完整隐私会计。表中 (1,1e-5) 不能直接宣称为 200/100 epoch 完整训练的总预算。采样收益还需明确批索引是否公开及对整个可观察 transcript 的机制定义。

DP 后处理只适用于噪声发布及公开信息的函数；如果模型更新或梯度同时使用未经保护的 TEE 分支秘密，不能未经证明就视为那次带噪残差的后处理。把 logits 保存在 TEE 只排除某类依赖置信度接口的攻击，不排除利用权重、梯度、残差或多轮观察的全部成员推断。

这些是对报告可支持结论的限制，不是声称已破坏某个经过完整形式化的 DP 实现。作者的单次分析、经验重建实验与整个训练协议的隐私保证应分别报告。

## 6. 实验与性能分母

作者使用支持 SGX 的 Xeon 与 NVIDIA RTX5000，模型 VGG16/19、ResNet18/34，数据 CIFAR10 与 ImageNet。训练取 weight decay 0.0005、momentum 0.9、初始学习率 0.1 和 cosine 调度，CIFAR 200 epoch、ImageNet 100 epoch；rank 从首卷积 1 开始按卷积或残差块倍增，ReLU/pool 不增。该经验策略不构成全域证明。

精度实验比较 Orig、Low-Rank、DP-X 与 AsymML。CIFAR 中 AsymML 相对 Low-Rank 的 1.45/2.59 为百分点提升；ImageNet 对应不同模型约 4.0–6.0 个百分点。图中 DP-X 有较大精度损失，但不据无完整数值表的柱形图编造所有模型精确准确率。

## 7. 攻击实验支持什么

模型反演使用 CIFAR 公共/私有数据划分、GAN 先验及首层带噪残差，允许标签知识和 200 次潜变量优化。Table 2 的 VGG16 为 PSNR 9.43、SSIM 0.12、重建分类准确率 10.74%；ResNet18 为 9.31、0.09、10.56%，接近十分类随机水平。这支持该配置下该攻击重建效果差，不覆盖全部属性泄漏或自适应联合观察。

梯度攻击使用 L-BFGS、batch64、最多 200 次迭代、随机目标权重，并比较带噪残差初始化。作者也指出原始 DLG 对 batch1 更有效、大 batch 较难。因此不能用该设置排除 batch1、已训练权重、多步聚合或更强攻击；优化损失低与视觉恢复差也不是正式隐私证明。

系统没有给出通用恶意 GPU 计算验证协议。若 GPU 返回错误、重放或选择性扰动结果，经验输入重建失败并不保证训练正确、任务可用或设备已停止访问。

## 8. 与 CCA GPU 主线和当前项目的关系

PORTAL/CAGE/ACAI 与本项目假设从受保护设备访问、归属和授权建立执行边界；AsymML 在不可信 GPU 上主动发布变换后的数据，接受条件性隐私和精度折衷。两类路线的 TCB、攻击者能力与安全目标不同，不能把残差低秩加噪当作 SMMU、固件和任务状态隔离的替代。

项目继续采用 RMM 认证原始 Client、可信 ProxyRealm 管 SMMU、实际 HPA/对象归属/权限/生命周期校验以及 GPU direct-HPA Stage-1 合成的设计假设。其他设备的硬件 Stage-2 同样授权；具体实验板硬件能力不用于否定架构研究假设。当前运行实现仍以 CURRENT_BASELINE 为准，不能据论文自动宣称这些目标均已实现。

可以吸收的设计问题是“合法映射之外，哪些派生数据可以对谁发布”：activation、梯度、KV、调试日志和模型更新应绑定 Client/对象/用途。若未来允许不可信 GPU 外包模式，需单列隐私契约、裁剪/敏感度、总预算、精度与完整性；作为可选上层机制，不增加为共享 GPU 必需主线。

中断设计仍需独立完成：物理 IRQ 只能提示检查状态；可信 Proxy 根据认证队列、private plan/snapshot、native fence、cookie/epoch 和 IRQ127 路由，绑定真正 Client 与任务终态。完成通知、数学正确性、DMA quiescence、撤销失效及清理后复用分别定义。AsymML 的 CPU/GPU context 切换不提供跨 VM 通知认证，也不解决迟到 IRQ、重复完成或旧映射复用。

优先可验证研究项：发布权限与全 transcript 定义；恶意结果/过期 epoch 的状态约束；取消/reset 后停止访问与清理屏障；通信批量优化保持逐任务归属和接收者绑定。低秩/噪声优化只在有明确应用需求时另行评估，不应稀释内存和中断隔离两条安全主线。

## 9. 结论与记录

本文价值是将低秩分解用于减少可信计算量，并把残差隐私与异构训练性能联系起来；主要边界为理论条件、完整训练隐私组合、实现可信归属和缺少恶意 GPU 完整性验证。它是与项目相邻的比较文献，而不是新的 CCA GPU 隔离架构。
