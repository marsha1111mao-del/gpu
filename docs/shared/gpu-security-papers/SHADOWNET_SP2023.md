## 2. 问题、威胁模型与安全目标

模型提供者希望把私有 CNN 部署在可被用户或攻击者控制的移动设备上，同时继续使用普通世界 GPU。仅加密磁盘模型不能阻止运行时明文提取；把所有模型放入当时的小型 TrustZone TEE 又有资源与性能成本。

攻击者控制 Normal World，包括 OS、外部缓冲区和 GPU 工作，可观察外包的权重、输入和输出。Secure World 的 TEE OS、TA、代码、私有数据与随机数被信任，侧信道排除。模型加载和证明被交给既有机制，论文未实现一套完整端到端证明与密钥供应协议。

主要目标是模型隐私，允许攻击者看到查询 API 的输入输出以及部分架构信息。它不保护用户向本地不可信应用提供的原始输入，也不消除合法 API 导致的模型提取。论文明确不研究推理完整性，建议另结合 Slalom；因此不能把 GPU 正确返回、任务隔离、中断真实或拒绝服务耐受视作本文已有保证。

## 3. 架构及模型转换

转换器离线将原 CNN 分成 Part A 和 Part B。Part A 的变换后线性层留在 TensorFlow Lite/Normal World/GPU；Part B 的恢复变换、mask 操作及非线性层放进 OP-TEE TA。TeeShadow 是跨世界调用占位算子；具有 shortcut 的网络使用 TeeMerge 接受多个分支输入并在可信端合并。

标准卷积先将各 kernel 变成 `λ_i·w_i+f_i`；由线性性，GPU 的计算结果等于原卷积缩放后再加随机 filter 的卷积。TA 用随机 filter 对应结果和缩放逆元恢复原输出。偏置、batchnorm 融合、量化和恢复顺序必须一致，不能把任意非线性直接套入线性等式。

优化方案只增加 `m−n` 个随机 mask kernels，m 由混淆比例 r 和原 kernel 数 n 决定；n 个原 kernel 分别复用其中某个 mask，加缩放后与 mask kernels 一起随机排列。GPU 统一计算 m 个输出，TA 根据秘密索引、排列和缩放做轻量恢复，避免在可信端重新计算完整随机卷积。

Depthwise 卷积另用输入/权重通道的相同排列和互逆缩放，使逐通道乘积的缩放抵消，再在 TEE 内恢复通道顺序；没有给每个 depthwise kernel 加独立加性随机向量。Dense 可转为 pointwise 卷积；这些方案均依赖具体线性结构，不是任意 GPU 指令的加密执行。

恢复需要 `λ_i` 非零，但部分文字写从整个域 F 采样、附录候选集也含零缩放，应补充从 F 的非零元素集合采样。正文写 `ceil(1.2×64)`，示例却给 76，而数学上向上取整为 77；这是参数/实现说明差异，不据此认定安全漏洞。

## 4. 中间值 mask 的生命周期

仅隐藏权重不够，攻击者可能根据真实中间输入输出推导参数。ShadowNet 把中间值量化嵌入有限域，加入与其同形状的均匀随机 M；TA 离线计算 `Conv(M,W)`，在线从恢复后的卷积结果中减去该值。每层、每轮推理都必须使用新的 mask。

首层原始输入和最终模型输出按威胁模型可公开，不能把所有输入输出都说成对 Normal World 加密。中间值的 one-time-pad 性质依赖域上正确采样、秘密材料不外泄和不复用；有限精度浮点随机扰动不能自动得到相同证明。

模型/恢复参数与一次性 mask 的保护是不同任务。一次性文件若可被 Host 重放，或者断连/reset 后游标回退，不能只凭“文件存入 TA”证明未复用；加载还需绑定模型版本、层、执行次序和输入输出维度。论文没有给出覆盖恶意并发 Client、取消和状态回退的完整材料消费协议。

## 5. 形式化分析究竟证明什么

Theorem 1 声称：给定 Normal World 观察，对变换权重所对应 feasible set 中的任意两个候选原权重，其后验概率相同。附录 B 通过选择 mask 索引集合、排列、缩放和 mask 对应关系枚举候选集，再使用中间值 OTP 与首尾层欠定方程的论述。

这不是通用模型隐私的模拟式证明。候选“可构造”不自动意味着后验概率均匀：还需说明原模型分布、变换随机性、不同候选的前像重数，以及公开输入输出与模型先验施加的约束。附录的 Eq.27 从集合构造直接跳到等概率，未展开这些条件。

Lemma 2 用首尾层单独不可解来主张无法从全模型输入输出恢复权重；未知数多的局部方程不能独立排除跨层结构、已知 backbone、特定模型先验或多次自适应查询的利用。公开 API 的泄漏本来就是允许项，不应据此给出“功能等价提取在所有网络上数学上不可能”的结论。

Depthwise 变换还有可直接看出的泄漏边界：非零标量乘法与通道排列保留每个 kernel 内的零元素位置和非零坐标比例，只隐藏整体尺度与通道标签。若攻击者拥有候选公共/预训练 kernel，这些不变量可用于匹配；这是从设计公式得到的条件性分析，未执行攻击，也不宣称已恢复论文模型。

标准卷积的候选集同样只包含已公开 transformed kernels 之间若干差向量的缩放组合；巨大候选数量不能自动排除结构信息泄漏或高效搜索。正文以约 `2^268` 个候选说明 r=1.2 足够安全，但它不等于 268-bit 密码安全强度，也不是攻击复杂度下界。独立观测的不同 transformed filters 的候选集更不能仅因 m 较大就自然具有包含关系。

论文另将“使用 ShadowNet 信息的攻击不比黑盒攻击显著更容易”标为 Conjecture 1，而不是已证定理。其文字用 `q′=O(q)` 描述这一想法，但单独大 O 上界并不能证明所需查询数不会显著更少；需要相应下界或归约。本报告保留猜想性质，不借实验把它升级成一般证明。

## 6. 攻击实验与正确性证据

两类攻击在特定 CIFAR-10 网络上评估。Knockoff 为 10K CIFAR-100 查询：victim81.6%、黑盒基线36.6%、重用 ShadowNet 权重31.1%、随机固定卷积36.2%。MixMatch 使用 8K 标注查询加 8K 无标注样本：分别98.1%、95.8%、92.3%、92.4%。不同攻击的 victim 训练方法也不同。

攻击改造固定变换后的卷积层、仅训练后继部分。实验说明这两套指定训练策略未从复用权重获得优势；它没有穷尽候选索引/缩放恢复、先验匹配或不同自适应攻击，也不能证明“变换权重不包含任何有用信息”。92.3% 的影子模型精度本身也不等于完全阻止功能复制。

预测一致性和准确率不同：ResNet44/404、MiniVGG、MobileNet 的 top1 一致性分别97%/96%/98%/88%，YOLOv4-tiny94%。MobileNet 原模型预测正确的子集为95%一致、错误子集74%；低置信度解释不能将总体88%改写为逐输入等价。

YOLOv4-tiny 的 mAP@0.5 从57.06%到55.90%，减少1.16个百分点。其他模型图示精度接近，但量化使数值语义变化；不能同时写“结果完全相同”与这些实测一致性。本文不从图柱目测补造未列出的精确准确率。

## 7. 原型、性能和资源口径

作者平台 Hikey960/Kirin960、4×A73+4×A53、Mali G71 MP8、3GB RAM，Android P、OP-TEE3.9.0、TF Lite 基于 TF2.2；有限域 `p=2^24−3`，量化 l=8、r=1.2。五个 CNN 包含 MobileNet、ResNet44/404、MiniVGG、YOLOv4-tiny，推理时延图报告100次均值。

论文说“增加0.6–1.6×”，并列额外252/30/5/281/451ms，对应1.6/1.1/0.6/1.5/0.7倍开销。这里是增加量与基线之比，不能直接当总延迟只有原始的0.6–1.6倍；应在原始逐项时间基础上区分额外开销率和总倍率。

GPU 相对 ShadowNet CPU 仅再减少约15/5/1/8/30ms，即4%/9%/8%/2%/3%。反复设置 GPU job 和跨世界交互限制收益。这不是设备不支持 GPU，而是该执行路线的通信/分割成本；不能将其数字移植成本项目直通或多 Client 性能。

一次性材料更新占据明显成本：MobileNet mask 数据约37MB、每轮更新约200ms；ResNet44约3.3MB、18ms。100实例 mask 再生成耗时分别 MiniVGG2.19s、ResNet44 20.29s、MobileNet97.26s、ResNet404 127.9s、YOLOv4-tiny25.5s；离线模型转换又另需数分钟至31分23秒。可信材料供应和在线加载应分别统计。

TA 静态分配及双缓冲减少碎片和中间空间；但 residual 分支的跨阶段值仍需有效生命周期，不能对任意 DAG 简单声称只有两个缓冲即可。可信端 MobileNet 约48MB，不能把最小模型4MB说成所有模型内存。

缓存 TA 代码/数据页映射可把 ResNet44 从106ms降到57ms，约1.86倍或46.23%时间减少，论文取约2倍；缓存的是仍有效的固定映射，参数页仍更新。对项目可借鉴映射复用的条件论证，不能省掉重授权、撤销失效和页复用检查。

TA 优化表1500→81ms是累计组合，且排除 mask weights 重载：Neon sqrt、缓存布局、循环顺序、预加载、Batchnorm/AddMask/ReLU6向量化共同生效。它不是整体模型时延，不宜把每步数字当独立可叠加收益。附录 sqrt 编译选项比较也不是同编译条件的单算法消融。

新增 TA 约2100 LoC、其中新操作不足200 LoC；OP-TEE OS、固件和依赖仍可信，转换器虽不增加设备驻留代码，却属于模型供应链正确性依赖。论文配置增加安全内存16→64MB、共享内存2→8MB；公开镜像说明另外写128MB，不能把不同载荷条件合并。

LSTM 仅一个1640参数小层原型，转换3640参数、33→41ms；不是完整 LLM、attention/KV-cache 或云多租户系统验证。选择性保护部分层和移植 SGX 均为讨论，不代替当前端到端 GPU 安全证明。

## 9. 与项目的关系

保持 RMM 认证原始 Client、可信 ProxyRealm 统一控制 SMMU，建图校验对象、实际 HPA、权限与生命周期，软件 IPA→HPA 合成受保护GPU Stage-1；其他设备继续硬件Stage-2。ShadowNet 不以此为前提，也不替代 GPUVM、认证队列、私有快照、native fence、cookie/epoch 和 persistent IRQ127。

项目两部分仍是直通/共享实现与性能，以及任务的内存/中断通信隔离。ShadowNet提供另一条“不把GPU纳入可信域”的应用保护路线，可用于比较可信基、交互次数和允许泄漏；不能把 transformed weights 的混淆当作跨Client访问控制。

对项目最直接的启发是约束跨域请求所能触发的状态转换：从哪个Client接收、处理哪个模型/层/任务、使用哪份输入快照、结果给谁，以及取消/reset后哪些旧状态失效。已有cookie/epoch和私有快照可作为基础，不另造重复身份框架。

若未来加入模型混淆或结果检查，应单独规定允许泄漏和数值语义，确保验证/使用/发布为同一份内容。真实fence与可信IRQ只关联实际任务终态，不会自动验证模型恢复计算或禁止黑盒提取；材料认证失败也不能发布成功完成。
